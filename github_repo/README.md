## О работе

Исследование посвящено сравнительному анализу четырёх методов информационного поиска применительно к задаче формирования контекста в RAG-системах:

- **BM25** — классический лексический поиск
- **Dense Retrieval (SBERT)** — нейросетевой семантический поиск
- **Hybrid (RRF)** — гибридный поиск (BM25 + Dense) через Reciprocal Rank Fusion
- **Hybrid + Reranking** — гибридный поиск с переранжированием через кросс-энкодер

Эксперимент проведён на стандартном бенчмарке **HotpotQA** (100 запросов, 1000 документов) с использованием большой языковой модели **Llama-3.3-70B** через Groq API.

## Главные результаты

Гипотеза о превосходстве метода **Hybrid + Reranking** подтверждена статистически по всем 10 метрикам (7 IR + 3 QA):

| Метод | nDCG@10 | MRR | Recall@10 | F1 (QA) | Время (мс) |
|---|---|---|---|---|---|
| BM25 | 0.7616 | 0.8772 | 0.8650 | 0.38 | 5.9 |
| Dense (SBERT) | 0.7930 | 0.8888 | 0.8900 | 0.42 | 11.1 |
| Hybrid (RRF) | 0.8009 | 0.9012 | 0.9200 | 0.43 | 13.8 |
| **Hybrid + Reranking** | **0.8700** | **0.9494** | **0.9450** | **0.49** | 81.8 |

**Прирост качества Hybrid + Reranking над BM25:** +14.2% по nDCG@10, +8.2% по MRR.
**Цена качества:** замедление обработки запроса в 5.9 раз.

## Быстрый старт

### Просмотр готовых результатов

Откройте файл **`notebooks/experiment_5f_6f_executed.ipynb`** прямо на GitHub — все ячейки уже содержат результаты выполнения. Никакого запуска не требуется.

### Запуск эксперимента с нуля

Если хотите воспроизвести эксперимент:

1. Откройте **`notebooks/experiment_5f_6f_combined.ipynb`** в [Google Colab](https://colab.research.google.com/) (бесплатно)
2. Получите API-ключ Groq на [console.groq.com](https://console.groq.com) (бесплатно)
3. Вставьте ключ в Блок 14 и запустите все ячейки

Подробная инструкция: **[docs/HOW_TO_RUN.md](docs/HOW_TO_RUN.md)**

## Архитектура эксперимента

```
HotpotQA (100 запросов × 1000 документов)
            │
            ▼
   ┌────────┴────────┐
   │  Retriever (4)  │  ← BM25 / Dense / Hybrid / Hybrid+Rerank
   └────────┬────────┘
            ▼

            │
```

## Используемые технологии

**Базовые библиотеки:**
- Python 3.10+
- NumPy, pandas, matplotlib

**Информационный поиск:**
- `rank-bm25` — реализация BM25
- `sentence-transformers` — модели SBERT и Cross-Encoder
- `faiss-cpu` — векторный индекс для Dense Retrieval

**LLM-генерация:**
- `groq` — API клиент для Llama-3.3-70B
- `datasets` — загрузка HotpotQA из HuggingFace Hub

**Оценка качества:**
- `bert-score` — BERTScore F1 для QA
